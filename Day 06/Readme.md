# JavaScript Interview Practice — Day 6

## 🎯 Focus

Interview-level JavaScript problem solving with arrays, objects,
recursion, and hash-map based approaches.

## 📝 Problems

### 1. Two Sum ⭐⭐⭐

Find two numbers whose sum equals the target and return their indices.

**Concepts:**

- Hash Map
- Array traversal
- Time & Space Complexity

---

### 2. First Non-Repeating Character ⭐⭐⭐

Find the first character that appears only once in a string.

**Concepts:**

- Frequency counting
- Objects / Hash Maps
- String traversal

---

### 3. Remove Duplicates Without `Set` ⭐⭐⭐

Remove duplicate values from an array without using `Set`.

**Concepts:**

- Objects
- Array traversal
- Lookup logic

---

### 4. Find the Second Largest Number ⭐⭐⭐

Find the second distinct largest number without sorting the array.

**Concepts:**

- Array traversal
- Comparison logic
- Optimization
- Time Complexity

---

### 5. Flatten a Nested Array ⭐⭐⭐⭐

Flatten a deeply nested array without using `.flat(Infinity)`.

**Concepts:**

- Recursion
- Arrays
- Nested data structures

---

## 🧠 Goal

For every problem:

- Understand the problem before coding
- Think about a solution independently
- Consider brute force vs optimized approaches
- Write the solution without copying
- Explain the logic
- Identify Time Complexity
- Identify Space Complexity
