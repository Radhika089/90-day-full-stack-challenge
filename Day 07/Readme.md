# JavaScript Interview Practice — Day 7

## 🎯 Focus

Real-world JavaScript problem solving using data transformation,

## 📝 Problems

### 6. Group Orders by Status ⭐⭐⭐⭐

Group orders based on their status such as Pending, Delivered,
and Cancelled.

**Concepts:**

- Objects
- Array traversal
- Data grouping
- Real-world dashboard logic

### 7. Calculate Revenue by Category ⭐⭐⭐⭐

Calculate total revenue for each product category using:

`revenue = price × sold`

**Concepts:**

- Objects
- `reduce()`
- Data aggregation
- Real-world business logic

---

### 8. Implement Your Own `map()` ⭐⭐⭐⭐

Create a custom `myMap()` function that behaves like JavaScript's
built-in `map()`.

**Concepts:**

- Higher-order functions
- Callbacks
- Arrays
- Function execution

---

### 9. Implement Debounce ⭐⭐⭐⭐⭐

Create a debounce function that executes a function only after
the user stops calling it for a specified delay.

**Concepts:**

- Closures
- `setTimeout`
- `clearTimeout`
- Callbacks
- Real-world search/API use cases

---

### 10. Build a Simple Retry Function ⭐⭐⭐⭐⭐

Create an async retry function that attempts an asynchronous
operation multiple times before finally throwing an error.

**Concepts:**

- `async/await`
- Promises
- `try/catch`
- Loops
- Error handling
- Retry logic

---

## 🧠 Goal

For every problem:

- Understand the requirement
- Build the logic independently
- Avoid copying solutions
- Explain the approach out loud
- Understand why the solution works
- Identify Time Complexity
- Identify Space Complexity
- Connect the problem to real-world development
